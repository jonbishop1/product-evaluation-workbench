## Agent and developer task

| Stage | Procedure | Evidence | State |
| --- | --- | --- | --- |
| Discover | Find the official task documentation | | Unknown |
| Understand | Identify prerequisites, constraints and costs | | Unknown |
| Act | Run the authorized procedure | | Not attempted |
| Verify | Compare output with the expected result | | Not attempted |
| Recover | Exercise a defined failure and recovery route | | Not attempted |

For data products, specify correctness, updates/deletes, reconciliation, freshness and recovery. For developer tools, specify supported runtime, installation and a real integration boundary. A documentation route or machine-readable file does not establish execution.
