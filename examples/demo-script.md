# Product evaluation demonstration script

Use this script for a short screen recording or a written walkthrough. No recording or publication is implied.

1. Show a fictional buyer task: evaluate 22,001 events under a plan with a $30 base, 20,000 included events and $1.50 whole-bucket overage.
2. Explain why the monthly volume, billing unit and rounding rule are separate inputs.
3. Run the README calculation. Show the $34.50 result and the three overage buckets.
4. Run the tests. Explain that passing arithmetic tests does not establish product suitability.
5. Open the evaluation workbook. Add the exact capability claim, expected output, source evidence and unresolved execution step.
6. Show the documentation-discovery example. Point out the explicit distinction between an observed prerequisite and a completed product operation.
7. Finish with a concrete question for the viewer: which buyer decision needs stronger evidence in your evaluation journey?

The public output should label the plan and product scenario as fictional. Do not replace the fixture with private customer material without appropriate authorization.
